# TrustFolio Metricool automation v1

Additive integration only. It does not modify the TrustFolio Node backend or existing ad-generation scripts. The publisher is intentionally one-post-at-a-time; no batch publishing command is included.

## What repository inspection established

- Source of truth: social_post_manifest_v1.json, generated by social_post_generator_v1.py.
- Manifest media URLs use https://media.trustfolio.in/feed/.
- The connected Metricool brand showed Instagram in the connected account data. Facebook was not shown as connected on that brand.
- The repository contains legacy creative IDs. Select an ad_id from the current server-generated social post manifest and verify that its media URL is current.

## Step 1 — Copy the script to the server without changing the daily Git checkout

Keep ~/daily_ads_git on its existing main branch. The daily timer expects that checkout; do not checkout the feature branch in that directory.

    cd ~/daily_ads_git
    git fetch origin feature/metricool-auto-publisher-v1
    git show origin/feature/metricool-auto-publisher-v1:metricool_publisher_v1.py > ~/new_scraper/ads/metricool_publisher_v1.py
    source ~/venv/bin/activate
    python -m py_compile ~/new_scraper/ads/metricool_publisher_v1.py

Do not merge this branch into main until the one-post test is complete.

## Step 2 — Public media verification (read-only)

Choose an ad ID present in the current ~/new_scraper/ads/social_post_manifest_v1.json:

    python ~/new_scraper/ads/metricool_publisher_v1.py --ad-id tf-aa5900f0c166 --verify-only

The script downloads the public image and checks HTTPS, HTTP status, content type, image decoding, dimensions, file size and SHA-256. It writes metricool_media_qa_v1.json. A PASS proves technical fetchability, not visual correctness. Open the exact image URL in the report and inspect text, product images, prices and branding.

If verification fails, do not schedule anything. Fix the public media bridge/URL or use a valid current manifest URL, then rerun verification.

## Step 3 — Confirm Metricool API access

Metricool documents API access on Advanced and Custom plans. In Metricool, open Account Settings > API and confirm an API access token is available. Do not paste it into chat, Git, command-line arguments or logs.

Create/update ~/new_scraper/.env with:

    METRICOOL_API_TOKEN=put_token_here
    METRICOOL_USER_ID=your_metricool_user_id
    METRICOOL_BLOG_ID=your_brand_blog_id
    METRICOOL_INSTAGRAM_CONNECTED=true
    TRUSTFOLIO_POST_TIMEZONE=Asia/Kolkata

Set METRICOOL_INSTAGRAM_CONNECTED=true only after confirming Instagram is connected to the exact METRICOOL_BLOG_ID. Keep Facebook publishing disabled until Facebook is connected and confirmed on the same brand. IDs must match the target account.

    chmod 600 ~/new_scraper/.env

## Step 4 — One-post visual QA and scheduling

Inspect the exact image from Step 2. Once it passes the visual check, schedule only that ad:

    set -a
    source ~/new_scraper/.env
    set +a
    python ~/new_scraper/ads/metricool_publisher_v1.py \
      --ad-id tf-aa5900f0c166 \
      --schedule-one \
      --qa-approved

This creates a live scheduled post with autoPublish=true, not a draft or review flow. Default schedule is 20 minutes in the future, or use --publish-at 'YYYY-MM-DDTHH:MM'. Do not run until the image has passed visual inspection and API access is confirmed.

The script stops if the image cannot be fetched, credentials or IDs are missing, Instagram connectivity is not explicitly confirmed, image normalization returns no mediaId, or the same ad/network is already recorded locally. The local state file is a duplicate guard, not a replacement for checking Metricool's actual planner.

## Step 5 — Verify the scheduled post

In Metricool Planner, confirm the right Instagram brand, attached image, caption/hashtags, destination URL, correct time and scheduled status. Save the Metricool response and QA report. Do not start bulk scheduling until these checks pass.

## Limitations

- This script supports one Instagram feed post per invocation.
- No Facebook or bulk publisher is included yet.
- The CLI flag is a one-time operator confirmation of visual QA; it does not create a Metricool approval workflow.
- If Metricool changes its media-normalization response shape, the script stops rather than guessing.
- Do not add this publisher to the daily timer yet. Finish public media verification and the one-post test first.
